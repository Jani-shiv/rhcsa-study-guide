# Security Policy

## Supported Versions

We provide security and accuracy fixes for the current active release branch of this study guide:

| Version | Supported          | Notes |
| ------- | ------------------ | ----- |
| 1.0.x (main branch) | :white_check_mark: | Actively maintained |
| Older releases | :x: | Please update to latest `main` |

---

## Reporting a Vulnerability or Security Concern

We take the security of this project, its dependencies, and the safety of our learners seriously.

If you discover a security vulnerability or exploit:

1. **Do not create a public issue**.
2. Please report the vulnerability privately via **[GitHub Private Vulnerability Reporting](https://github.com/Jani-shiv/rhcsa-study-guide/security/advisories/new)** (if enabled on the repository), or open a confidential discussion.
3. Include the following details:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - The potential impact on users or deployments.
   - Any proposed remediation or patch if available.

### What to Expect

- **Acknowledgment**: You will receive an initial response acknowledging your report within 48 to 72 hours.
- **Investigation**: We will investigate the validity and severity of the report.
- **Resolution**: Once confirmed, a fix will be developed and released to the `main` branch promptly, with credit given to the reporter (unless anonymity is requested).
